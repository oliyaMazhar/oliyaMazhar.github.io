BlackSmith: Meta-Orchestration & Bounded Autonomy

Python • LangChain • LangGraph • FastAPI • SQLite GITHUB.COM/OLIYAMAZHAR/BLACKSMITH ↗
ARCHITECTURAL THESIS // INDEPENDENTLY CONCEIVED & ENGINEERED AT AGE 18

BlackSmith is a meta-orchestration framework for dynamic AI sub-agent generation with configurable autonomy boundaries, providing structured governance for multi-agent workflows operating in enterprise environments. Positioned as the first open-source, domain-general framework producing quantitative empirical findings on how autonomy boundary configuration affects agent reliability — addressing a critical research gap left unaddressed by commercial platforms such as Vertex AI Agent Builder, Salesforce Agentforce, and Azure AI Foundry.

01. BOUNDARY VECTOR B ∈ [0,1] + CHECKPOINT D

Continuous boundary configuration vector governing Autonomous, Assisted, and Halted decision states per action class, layered with a Decision Checkpoint Set enforcing hard-stop conditions for irreversible operations independent of B.

02. CUSTOM ENFORCEMENT ENGINE

Intercepts every agent decision node before execution, evaluating actions against global halt conditions, computing the effective boundary via a floor-clamped max(B, D) operation, and routing to tool execution or a structured Human-in-the-Loop checkpoint.

03. SANDBOXED EVALUATION ENVIRONMENT

Executes structured scenario suites across Normal, Edge Case, Adversarial, and Failure Injection categories to stress-test generated sub-agents under varying governance constraints without live production risk.

04. NUMERICAL GRADIENT BOUNDARY OPTIMISER

Iteratively refines autonomy configurations via numerical gradient estimation, improving Task Completion Rate, Decision Consistency Score, and Failure Mode Containment Rate while respecting D-value safety floors.

EMPIRICAL RESEARCH POSITIONING

Why BlackSmith Exists vs. Commercial Suites

Commercial orchestration platforms offer static guardrails but lack a continuous mathematical formulation of autonomy boundaries or reproducible datasets measuring the autonomy-reliability tradeoff.
